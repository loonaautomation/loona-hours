How It Works

Press a preset chip (or set the boxes), then Start. The page stores one thing: the exact finishing moment, calculated as now + the time you set. Every screen refresh then shows finish time − now, recomputed from your device clock. That is why this timer cannot drift: a timer that simply counts its own ticks loses time whenever the browser slows the tab down, but a finish-time timer is correct the instant you come back to it — even after the tab has slept.

When the remaining time reaches zero, the page plays a repeating beep through the Web Audio API and flashes “⏰ Time is up!” in the tab title until you return. Pause freezes the remaining time; Reset reloads whatever is in the boxes.

Frequently Asked Questions

Does this timer keep working if I switch tabs or my screen sleeps?

Yes. The timer is built on a finish timestamp, not on counting screen updates. Browsers throttle background tabs, but every time the page wakes up it recomputes the exact remaining time from your clock, and it still fires the moment the finish time passes.

Why can I not hear the alarm?

Browsers only allow sound after you have interacted with the page — pressing Start counts, so the alarm is unlocked. Check the device volume and that the tab is not muted (right-click the tab in some browsers). The tab title also flashes when the timer ends, so a silent room still gets a visual signal.

What is the longest timer I can set?

Up to 99 hours, 59 minutes and 59 seconds with the boxes — far beyond any preset. For a target that is days away, the Countdown to Any Date tool on this site is a better fit because it names the event and counts days as well.

Can I run two timers at once?

Open this page in a second tab — each tab keeps its own independent timer with its own finish time and alarm.

Is my timer saved if I close the page?

No — closing the tab discards the timer. Keep the tab open (it can sit in the background) for as long as the countdown matters.

How it works — the maths

The only arithmetic is a subtraction, done fresh on every refresh:

The formula:
Finish time = the moment you press Start + the duration you set
Remaining = finish time − now, recomputed from the clock on every tick (never by counting ticks)
Ring fraction = remaining ÷ duration

Worked example

You tap the 10 min preset at exactly 9:41:00 AM and press Start. The page stores a finish time of 9:51:00 AM. You switch to another tab for seven minutes; when you glance back at 9:48:12 AM the timer shows 2:48 remaining — exactly right, because it subtracted the current time from 9:51:00 rather than trying to count 420 one-second ticks in a sleeping tab. At 9:51:00 the remaining time hits zero, the beep sounds and the title starts flashing.
