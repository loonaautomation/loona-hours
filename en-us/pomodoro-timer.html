How It Works

The Pomodoro Technique splits work into timed sprints: focus completely for one session, rest briefly, repeat, and take a longer rest after a set of sessions. This timer encodes that whole schedule as a timeline. When you press Start it notes the time; from then on, your current phase is worked out from how much time has passed since that moment. Focus sessions, breaks and the session counter can therefore never drift, skip or double-fire — if the tab sleeps through a whole break, you return to find the timer already in the correct next phase.

Three beeps mark the start of a break, two beeps mark the start of a focus session. Pause freezes the timeline; Reset clears it so new settings can take effect.

Frequently Asked Questions

What are the classic Pomodoro lengths?

25 minutes of focus and a 5-minute break, with a 15–30 minute long break after four sessions — the settings this timer starts with. They come from Francesco Cirillo’s original technique, but every number here is adjustable before you start.

Do I have to press anything when a break starts?

No. The phase changes automatically at the scheduled moment and the beeper sounds — short breaks, the long break and the next focus session all arrive on their own until you pause or reset.

What happens if I leave the tab in the background?

The schedule is derived from timestamps, so nothing is lost. If the tab sleeps through a break, you come back to the timer already showing the correct current phase with the correct time remaining — never a stale, drifted count.

Can I change the lengths mid-cycle?

Settings apply to the next fresh cycle: press Reset, edit the numbers, then Start. This keeps the running timeline consistent instead of silently reshaping a session you are halfway through.

How is the session counter worked out?

A session counts as completed the moment its focus block ends and a break begins. The counter is computed from the same timeline, so it stays right even after the tab has been asleep.

How it works — the math

One full cycle is a fixed block of time, and your position inside it decides everything:

The formula:
One cycle = (focus + short break) × (sessions per set − 1) + focus + long break
With the defaults: (25 + 5) × 3 + 25 + 15 = 130 minutes per cycle
Current phase = walk the schedule with (now − start time), taken modulo one cycle

Worked example

You press Start at 9:00 AM with the default settings. Focus runs 9:00–9:25, break 9:25–9:30, focus 9:30–9:55, break 9:55–10:00, focus 10:00–10:25, break 10:25–10:30, focus 10:30–10:55 — the fourth session — and then the long break runs 10:55–11:10, with the counter showing 4 sessions completed. At 11:10 a new cycle begins automatically. Check the timer at 10:47 and it shows focus session 4 with 8 minutes left — because 107 minutes have passed since 9:00, and minute 107 of the schedule sits 17 minutes into the fourth focus block.
