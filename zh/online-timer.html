使用方法

按下一个预设片（或设置好输入框），然后开始。页面只存储一样东西：精确的结束时刻，计算方式为 现在 + 您设置的时间。然后每次刷新屏幕都会显示 结束时间 − 现在，从您设备的时钟重新计算。这就是为什么本计时器不会漂移：一个只数自己滴答的计时器，每当浏览器减慢标签页时就会丢时间，但一个结束时间计时器在您回到它的一瞬间就是正确的 — 即使标签页睡过。

当剩余时间到零时，本页通过 Web Audio API 播放重复的提示音，并在标签页标题中闪烁“⏰ 时间到！”直到您回来。暂停会冻结剩余时间；重置会重新加载输入框中的任何内容。

常见问题

如果我切换标签页或屏幕休眠，这个计时器还会继续工作吗？

是的。计时器基于一个结束时间戳，而不是数屏幕更新。浏览器会节流后台标签页，但每次页面醒来时，它都会从您的时钟重新计算确切的剩余时间，而且它仍会在结束时间过去的那一刻触发。

为什么我听不到闹钟？

浏览器只允许在您与页面互动之后发声 — 按开始算数，所以闹钟被解锁了。检查设备音量，以及标签页没有被静音（在某些浏览器中右键单击标签页）。计时器结束时标签页标题也会闪烁，所以一个安静的房间仍有视觉信号。

我能设置的最长计时器是多少？

用输入框最多可达 99 小时、59 分钟和 59 秒 — 远远超出任何预设。对于几天之外的目标，本站的“倒计时到任何日期”工具更合适，因为它给活动命名并计算天数。

我可以同时运行两个计时器吗？

在第二个标签页打开本页 — 每个标签页都有自己独立的计时器、结束时间和闹钟。

如果我关闭页面，我的计时器还保存吗？

不 — 关闭标签页会丢弃计时器。只要倒计时还重要，就保持标签页打开（可以放在后台）。

运作方式 — 数学原理

唯一的算术是减法，每次刷新都重新计算：

公式：
结束时间 = 您按开始的时刻 + 您设置的时长
剩余时间 = 结束时间 − 现在，每次跳动都根据时钟重新计算（从不靠数跳动次数）
圆环比例 = 剩余 ÷ 总时长

计算示例

您点击 10 分钟 预设恰好在 上午9:41:00 然后按开始。页面会存储一个结束时间为 上午9:51:00。您切换到另一个标签页七分钟；当您在上午9:48:12回看时，计时器显示 2:48 剩余 — 恰好正确，因为它从 9:51:00 中减去了当前时间，而不是试图在一个睡着的标签页中数 420 个一秒的滴答。在 9:51:00 时，剩余时间到零，提示音响起，标题开始闪烁。
